# 비트코인 저축 현황 대시보드

나만의 Bitcoin DCA 트래킹 대시보드 — 아이폰 최적화, GitHub Pages 배포용

## 기능

- **과거 보유분 + DCA 통합 현황** — 20~22년 매수분과 월간 DCA를 합산해서 보여줌
- **실시간 BTC 가격** — 60초마다 자동 업데이트 (CoinGecko API)
- **자유로운 입력 추가** — 같은 달에 여러 번 추가 가능, 모두 합산해서 표시
- **목표 BTC 설정** — 카드 탭해서 목표 수량 수정, 진행률 자동 계산
- **월별 그룹 히스토리** — 달별로 묶어서 합산 표시, 항목별 삭제 가능
- **데이터 저장** — localStorage에 자동 저장 (앱 재시작해도 유지)

## 입력 방법

### 처음 설정 (1회만)
- **"과거 보유분 설정"** 버튼
- 20~22년 총 투자금 (코인 손실분 포함해서 실제 쓴 돈 전체)
- 현재 BTC 보유량 입력

### 매달 입력 (월 1회 이상)
- **"+ 입력 추가"** 버튼
- 연월 선택
- 투자금 (원화) + BTC 획득량 입력
- 같은 달에 여러 번 추가해도 자동으로 합산돼요

### 목표 BTC 수정
- 목표 BTC 카드 탭 → 원하는 수량 입력 → 저장

## GitHub Pages 배포 방법

### 1단계 — 저장소 만들기
1. GitHub에서 새 저장소 생성 (예: `btc-saving`)
2. Public으로 설정
3. **"Add a README file"** 체크 후 생성

### 2단계 — 파일 업로드
저장소 메인 페이지 → **"uploading an existing file"** 클릭
파일 4개 드래그앤드롭:
- `index.html`
- `manifest.json`
- `icon.png`
- `icon-512.png`

Commit changes 클릭

### 3단계 — Pages 활성화
Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save

### 4단계 — 접속
1~2분 후 `https://[깃헙아이디].github.io/btc-saving/` 접속

## 아이폰 홈 화면에 추가

1. 사파리에서 위 주소 접속
2. 하단 공유버튼 (□↑) 탭
3. "홈 화면에 추가" 선택
4. 이름 확인 후 "추가"

앱처럼 전체화면으로 실행됩니다 🎉
